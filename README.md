## Ubutool

# Information

Ubutool Is A Simple Tool For Ubuntu Linux

# Instalation

If You Want To Install Ubutool Follow Instructions

```bash
  git clone https://github.com/sn1p3rx7/ubutool
```

If You Don't Have Git(Github) then use:
```bash
  sudo apt update && sudo apt install github
```
Now:
```bash
  cd ubutool && sudo ./linux.sh
```

# How To Use

To Use Ubutool

Just After Installation Process Type:
```bash
  ubutool
```



Now You Will See This:

```
Ubutool v0.1.0
Type "help" to see available commands.

ubutool@USERNAME>
```

If You Type "help" You Will See All Commands, I Put The Commands Also Here:

```bash
  help - Show Commands
  ram - Show Ram
  disk - Show disk Usage
  info - Show System Info
  uptime - Show System Uptime
  update - check For Available Upgrades
  clear - Clear Actual Terminal
  version - show Ubutool Version
  exit - Exit Ubutool
```

You Can also do multiple commands at once e.g.
```bash
  ram && disk
```
Or 
```bash
uptime && update && clear && version && clear && ram
```
